### 역할분담

#### 조성훈

- 프로젝트 초기 세팅
- zustand-persist를 활용하여 localStorage 통해 찜 목록 관리
- 프로필 수정, 나의 모임, 나의 리뷰, 내가 만든 모임 구현
- react-query의 useInfiniteQuery를 사용하여 무한 스크롤 구현
- react-query의 setQueryData를 사용하여 데이터 관리
- jest, cypress로 마이페이지, 찜 기능 테스트 코드 작성

#### 김시몬

- 홈 페이지 , 상세 페이지 초기 10개 데이터 SSR 처리 이후 react-query의 useInfiniteQuery를 사용하여 데이터 무한 스크롤 기능(CSR) 구현
- 홈 페이지 , 상세 페이지, 찜 목록 페이지 필터링 기능 구현 (지역, 날짜, 마감 임박, 참여 인원, 4가지 타입(달램핏, 워케이션, 마인드풀니스, 오피스 스트레칭))
- 모임 생성, 모임 취소, 링크 공유 기능 구현(주최자) , 모임 참여 및 취소 기능 구현(참여자)
- 상세 페이지 리뷰 목록 페이지 네이션 기능 구현
- 로컬 Storage에 저장된 찜 목록 데이터를 이용하여 찜 목록 페이지 구현
- 홈페이지, 상세 페이지, 찜 목록 페이지 Cypress 테스트 코드 작성
- framer motion을 이용하여 모임 목록 스크롤 애니메이션, 필터링 탭 애니메이션 구현

#### 오동혁

- Zod와 React-Hook-Form을 이용하여 로그인 및 회원가입 기능 구현
- Axios interceptor를 이용하여 전체적인 에러 처리 구현
- 알림 메시지를 보여주는 Toast 컴포넌트 구현
- 서버와 클라이언트를 구분하여 Axios 인스턴스 구현
- 로그인 및 회원 가입 페이지 Cypress 테스트 코드 작성

#### 남윤하

- 모든 리뷰 페이지 필터링 기능 구현 (지역, 날짜, 최신순, 리뷰 높은 순, 참여 인원, 4가지 타입(달램핏, 워케이션, 마인드풀니스, 오피스 스트레칭))
- Zod와 React-Hook-Form을 이용하여 모임 만들기 모달 구현
- prefetchInfiniteQuery를 이용하여 모든 리뷰 페이지 구현
- 사용자 UX 향상을 위해 스켈레톤 구현
- Jest 유닛 테스트 코드 작성
- framer motion을 이용하여 필터링 탭 애니메이션 구현
